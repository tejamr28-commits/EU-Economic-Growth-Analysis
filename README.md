**EU Economic Growth Analysis**

Project Overview : 

This project analyzes economic growth trends across EU and Euro Area countries using quarterly GDP data.

A)Objectives

- Compare EU and Euro Area GDP growth trends.
- Analyze country-level percentage changes.
- Identify economic growth patterns and differences.

B)Tools Used:

- Microsoft Excel
- Data Analysis
- Charts and Dashboard Visualization

*Key Focus:
Understanding regional economic performance through data analysis and visualization.
